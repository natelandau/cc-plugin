# Base (imperative) verbs for the commit-message hook's `force_imperative` rule.
#
# One lowercase verb per line; `#` starts a comment. List only the base form
# ("add", not "added"). The hook strips -s, -es, -ies, -ed, -ied, and -ing from
# a subject's first word and blocks it when the result is a verb listed here,
# so "rings" is caught only if "ring" is listed, and "ring" itself always
# passes. A word that is not listed is never blocked, so a missing verb only
# lets a non-imperative subject through. Add the base verb to fix that.
#
# Two other line forms, grouped at the end of the file:
#   built -> build   an irregular form the suffix rules cannot reach
#   -user            a word that is never accepted as the first word, for
#                    non-verbs that subjects open with ("user-uploaded avatars")
#   !names           a word that is never blocked, such as a plural noun that
#                    looks like an -s form of a listed verb ("names" from "name").
#                    Do not exempt -ing words: a subject starting "linting"
#                    must say "lint".
#
# Seeded from pydocstyle's imperatives.txt (MIT License, Copyright (c) 2012
# GreenSteam, (c) 2014-2020 Amir Rachum, https://github.com/PyCQA/pydocstyle).
